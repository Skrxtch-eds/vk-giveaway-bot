# Соответствие ТЗ

Таблица сопоставляет требования со сценариями приложения. Учтены условия: 5 победителей по 2 билета, до 5 резервных и 48 часов на ответ.

| Пункт | Реализация |
|---|---|
| 1.2 | Приветствие, баннер, пять кнопок меню |
| 2.1 | Уникальная выдача кода; повторный запрос возвращает прежний код и инструкцию |
| 2.2 | При исчерпании кодов участие остаётся доступным |
| 3.1–3.2 | Ссылка на партнёра и автоматическая проверка подписки |
| 3.3 | Регистрация с датой и временем; повторные проверки без ограничения; ошибка API отличается от отсутствия подписки |
| 3.4 | Одна заявка на пользователя и партнёра |
| 4.1 | Код или регистрация дают один шанс за день, максимум 10 |
| 4.2 | Число шансов, активные дни, партнёры, оставшиеся дни и главный приз |
| 5.1 | Случайный выбор без повторов, настройка призов, снимок участников, CSV, подтверждение администратором |
| 5.2 | Выбор с учётом шансов: 5 разных победителей по 2 билета и до 5 резервных |
| 6.1–6.2 | Уведомления и кнопка «Получить приз» |
| 6.3 | Имя, фамилия, явное согласие; через 48 часов приз переходит резервному |
| 7 | Очередь уведомлений и проверка разрешения на сообщения |
| 8 | Пользователи и новые по дням, запросы и выдачи кодов, остатки, участники розыгрышей |

## Уточнения

- Число дней задаётся календарём; максимум 10 относится к шансам, а не к длительности акции. При повторе партнёра пользователь получает только одну заявку на него за всю акцию.
- Время акции по умолчанию московское; в базе — UTC.
- Подписка проверяется при регистрации. Устаревшая кнопка не регистрирует в другом дне.
- Дневной приём заявок заканчивается в полночь; `draw_at` задаёт время подведения итогов после неё.
- Повторный запуск не перевыбирает победителей. Один человек может побеждать в разных розыгрышах.
- Срок 48 часов начинается при предложении приза: после подтверждения результатов либо назначения резерва. Имя без согласия не подтверждает получение.
- При нехватке участников выбираются только существующие люди; число неразыгранных призов отражается в результатах. При исчерпании резерва новые победители не назначаются.
- В остаток дней входит текущий день, если шанс за него ещё не получен. Повторное нажатие увеличивает число запросов кода, но не выдач.
- Выгрузка содержит имена после согласия. Незавершённый ввод удаляется при отмене или просрочке.

## Вспомогательные инструменты

Демо, проверка доступа, загрузка баннера, резервные копии и Docker служат для запуска и сопровождения. Пользовательское меню сохраняет пять разделов из ТЗ; дополнительные игровые механики не добавлены.
