# Проверка

21.10.2026: **85 тестов прошли**. Среда: Windows, Python 3.12.14, SQLite 3.53.1.

```console
python -m unittest discover -s tests -t . -q
```

Проверены:

- выдача кодов, исчерпание запаса и одновременные запросы;
- подписка, регистрация, один шанс за день и смена даты;
- календарь короче и длиннее 10 дней, предел 10 шансов и одна заявка при повторе партнёра;
- выбор по весам, отсутствие повторных победителей и подтверждение результатов;
- согласие, граница 48 часов и переход приза резервному;
- права администратора, повторные события, перезапуск и восстановление очереди;
- статистика, CSV, резервная копия и запуск демонстрации;
- баннер в приветствии, разные призы партнёров, текст финального приза и исключение административных команд из счётчика запусков;
- полный сценарий: 12 участников, 10 дней, финал, подтверждение приза и резерв.

Также проверены синтаксис, конфигурация, баннер и подсказка при запуске из неполностью распакованного архива.

Тесты используют имитацию ответов API. Проверка на подключённом сообществе и сборка Docker ещё не выполнялись.
