# Бот промокодов и розыгрышей

Бот выдаёт промокоды, проверяет подписку на партнёров и проводит розыгрыши. За активный день начисляется один шанс в финале, максимум — 10; финал выбирает 5 победителей по 2 билета и до 5 резервных.

Приложение использует Python 3.12+ и SQLite. Установка дополнительных пакетов не требуется.

## Демонстрационный режим

Демо позволяет пройти сценарии акции с демонстрационными подписками и кодами. Общение с ботом происходит в консоли: вместо нажатия кнопок вводятся их названия.

1. Полностью распакуйте архив через **«Извлечь все»**.
2. В папке `vk_giveaway_bot` откройте **`Запустить демо.cmd`**.
3. Введите `Начать`, затем, например, `Получить промокод` или `Мои шансы`.

Запуск из терминала: `python -m giveaway demo`. Для участия в розыгрыше дня введите `Участвовать в розыгрыше`, затем `:subscribe` и `Проверить подписку`.

| Команда демо | Назначение |
|---|---|
| `:user 102` | Переключиться на участника 102; администратор — 101 |
| `:subscribe` / `:unsubscribe` | Изменить подписку на текущего партнёра |
| `:day 2` | Перевести время на второй день акции |
| `:finish` | Перейти к итогам и подготовить результаты |
| `/draw final` | Посмотреть результаты финала |
| `/approve final` | Подтвердить финал и отправить уведомления в консоль |
| `:claim 1` / `:consent 1` | Начать получение приза / подтвердить согласие после ввода имени и фамилии |
| `:advance 48` | Перевести время на 48 часов для проверки резерва |
| `:quit` | Завершить демонстрацию |

В командах получения приза используется номер предложения из уведомления. Состояние сохраняется после выхода; для выбора 5 победителей и 5 резервных нужны минимум 10 разных участников, получивших код или зарегистрировавшихся в розыгрыше.

## Подключение сообщества

Для подключения нужны ключ сообщества, календарь акции и материалы партнёров. Файлы `examples/` содержат примеры, которые необходимо заменить перед запуском.

1. Скопируйте `examples/campaign.demo.json` в `config.local.json`. Установите `demo: false`, укажите даты, партнёров, призы, правила и текст согласия. Даты уникальны; при повторе партнёра сохраняется тот же `partner_id`.
2. Скопируйте `.env.example` в `.env` и заполните `VK_GROUP_ID`, `VK_GROUP_TOKEN`, `VK_ADMIN_IDS`. Указанные администраторы подтверждают результаты и управляют рассылками.
3. Включите сообщения, ботов и клавиатуру сообщества. Ключу нужны права на сообщения и фотографии; для Long Poll 5.199 включите события `message_new`, `message_allow`, `message_deny`. Администратор должен разрешить сообщения сообщества.
4. Проверьте доступы и загрузите баннер, заменив число в команде на ID администратора:

```console
python -m giveaway check
python -m giveaway check-vk
python -m giveaway upload-banner assets/welcome.png --peer-id 123456789
```

Результат загрузки запишите в `banner_attachment` до импорта кодов. Если проверка партнёра требует отдельного ключа, добавьте `VK_PARTNER_TOKEN_partner_1` в `.env`.

5. Подготовьте файл UTF-8 с одним промокодом в строке. Загрузите его для нужной даты из конфигурации и запустите бот:

```console
python -m giveaway import-promos 2026-10-21 examples/promocodes.txt
python -m giveaway run
```

Дата в команде приведена для примера. Календарь может иметь любое число дней, но участник получает не больше 10 финальных шансов.

После появления пользователей или кодов настройки фиксируются, чтобы условия акции не менялись во время её проведения. Запас кодов и ключи `.env` можно обновлять; для следующей акции используются отдельные конфигурация и база через `--config` и `--db`.

## Управление

Команды в чате доступны только администраторам из `VK_ADMIN_IDS`. Розыгрыши проводятся автоматически; перед отправкой уведомлений администратор проверяет и подтверждает сохранённый результат.

| Команда | Назначение |
|---|---|
| `/admin` | Показать список команд |
| `/stats` | Показать статистику акции |
| `/draws` | Показать проведённые розыгрыши |
| `/draw ID` | Показать участников, победителей и резерв |
| `/approve ID` | Подтвердить результаты и поставить уведомления в очередь |
| `/broadcast КЛЮЧ ТЕКСТ` | Отправить уведомление участникам; уникальный ключ защищает от повтора |

ID финала — `final`, дневного розыгрыша — `daily:2026-10-21`. Победитель вводит имя и фамилию и даёт согласие; без подтверждения в течение 48 часов приз переходит резервному. Срок начинается при предложении приза после утверждения результатов или назначения резерва.

Через консоль также доступны выгрузка, резервная копия и повтор неудачных отправок. Сообщения из очереди отправляются, пока работает `run`.

```console
python -m giveaway export final exports/final.csv
python -m giveaway backup backups/bot.sqlite3
python -m giveaway retry-failed
```

CSV содержит участников, результаты и данные победителей, давших согласие. Остальные команды и параметры описаны в `python -m giveaway --help`.

## Размещение и проверка

Для постоянной работы нужен один запущенный экземпляр приложения. После перезапуска сохраняются база, результаты и очередь; копия работающей базы создаётся командой `backup`.

Для Docker предусмотрен `docker compose up --build -d`. До запуска нужны `.env`, файл `config.local.json` и каталог `data/`, доступный для записи пользователю контейнера UID 1000.

Автоматические тесты проверяют сценарии акции и восстановление после сбоев с имитацией ответов API:

```console
python -m unittest discover -s tests -t . -q
```

Проверка в подключённом сообществе и сборка Docker ещё не выполнялись. Уведомления отправляются сообщениями сообщества; показ телефонного пуша зависит от настроек получателя.
